# Green City Real Estate — Маркетинговые лендинги (Lovable)

Комплекс посадочных страниц, созданных для агентства недвижимости **Green City Real Estate** (Дубай, ОАЭ) на платформе Lovable. Проекты разработаны для быстрого тестирования маркетинговых гипотез и сбора лидов из таргетированной рекламы.

* **Статус:** В продакшене.
* **Розовый лендинг/квиз:** [https://uae.greencityre.org/]
* **Автоворонка:** [https://properties.greencityre.org/]
* **Зеленый лендинг/квиз:** [https://ae.greencityre.org/]
* **Инструменты:** Lovable

## 💼 Суть проектов и бизнес-задачи
Лендинги проектировались под мобильный трафик из социальных сетей с фокусом на высокую конверсию:
1. **Генерация лидов:** Интеграция форм обратной связи и квизов для сегментации клиентов (бюджет, цель покупки, гражданство).
2. **Маркетинговый трекинг:** Подключение Facebook Pixel, Google Tag Manager и Яндекс Метрики для отслеживания целевых действий.
3. **Оптимизация скорости:** Использование чистого кода на React (который генерирует Lovable) позволило добиться моментальной загрузки страниц на смартфонах.
